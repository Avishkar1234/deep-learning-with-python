# Chapter 1 — Key Takeaways

## Core Concepts

- **AI:** The broader field of building intelligent systems.
- **Machine learning:** Learning patterns from data.
- **Deep learning:** Learning representations using multilayer neural networks.
- **Representation:** A transformation or encoding of information useful for a task.
- **Loss function:** Measures the error according to a chosen objective.
- **Backpropagation:** Computes gradients of the loss with respect to model parameters.
- **Optimizer:** Uses gradients or other optimization information to update parameters.
- **Foundation model:** A broadly trained model that can support multiple downstream tasks.

## Training Process

1. Input data passes through the model.
2. The model produces predictions.
3. The loss function evaluates the predictions.
4. Backpropagation computes gradients.
5. The optimizer updates parameters.
6. Training repeats.

## Important Distinctions

- Backpropagation computes gradients; an optimizer updates parameters.
- Training loss measures performance on training examples, not necessarily unseen data.
- Deep learning is a subset of machine learning, which is a subset of AI.
